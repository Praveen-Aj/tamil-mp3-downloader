# V5.6 — Playlists, Ratings & Favorites Subsystem

## Overview
Phase V5.6 introduces user-curated **Playlists**, **Star Ratings (1-5)**, **Favorites**, and **External Playlist Importing** to the Tamil MP3 Downloader application. This feature provides music listeners with complete autonomy to create personalized collections, rate tracks, tag favorites, reorder playlist entries interactively, and download missing songs in bulk with physical disk reconciliation.

---

## Architecture & Relational Schema Integration

V5.6 leverages and extends the normalized relational tables established in V5.1 without breaking changes:

```
┌────────────────────────────────────────────────────────┐
│                       playlists                        │
│  (id, name, description, cover_url, is_smart, ...)     │
└──────────────────────────┬─────────────────────────────┘
                           │ 1:N (CASCADE delete)
                           ▼
┌────────────────────────────────────────────────────────┐
│                    playlist_items                      │
│  (id, playlist_id, song_id, position, added_at)        │
└──────────────────────────┬─────────────────────────────┘
                           │ N:1 (canonical link)
                           ▼
┌────────────────────────────────────────────────────────┐
│                         songs                          │
│  (id, canonical_hash, title, artist, album, state...)  │
└──────────────────────────┬─────────────────────────────┘
                           │ 1:1
                           ▼
┌────────────────────────────────────────────────────────┐
│                  user_song_metadata                    │
│  (song_id, rating [1-5], is_favorite, favorited_at...) │
└────────────────────────────────────────────────────────┘
```

### Key Schema Elements:
1. **`playlists` Table**:
   - `id`: Auto-incrementing primary key.
   - `name`: User-defined playlist title (UNIQUE).
   - `description`: Optional user description or notes.
   - `cover_url`: Optional custom or auto-derived artwork.
   - `created_at` & `updated_at`: ISO timestamp tracking.

2. **`playlist_items` Table**:
   - `(playlist_id, song_id)`: Unique constraint ensuring a song appears once per playlist.
   - `position`: Sequential 1-based order for manual reordering.
   - `ON DELETE CASCADE` foreign keys: Deleting a playlist automatically purges playlist items while leaving canonical songs and physical audio files completely intact.

3. **`user_song_metadata` Table**:
   - `song_id`: Foreign key linked to canonical `songs(id)`.
   - `rating`: Integer constraint `CHECK (rating IS NULL OR (rating >= 1 AND rating <= 5))`.
   - `is_favorite`: Boolean flag (0 or 1).
   - `favorited_at`: Timestamp recording when the track was marked favorite.

## Service Layer: LibraryService API

The `LibraryService` provides cohesive methods for playlist and user metadata management:

- **Playlists CRUD**:
  - `get_playlists_page(query, limit, offset)`: Paginated playlist cards with computed track counts and download metrics.
  - `create_playlist(name, description)`: Creates a new playlist.
  - `update_playlist(playlist_id, name, description)`: Edits playlist metadata.
  - `delete_playlist(playlist_id)`: Safely deletes playlist and its items.
  - `get_playlist_details(playlist_id)`: Returns full metadata and statistics (`total_songs`, `downloaded_songs`, `missing_songs`).
  - `get_playlist_items_page(playlist_id, query, limit, offset)`: Detailed tracklist ordered by position with rating, favorite, and download state.
- **Track Reordering**:
  - `reorder_playlist_items(playlist_id, ordered_song_ids)`: Mass position update.
  - `move_playlist_item(playlist_id, song_id, direction)`: Swaps position with adjacent track ('up' or 'down').
- **Ratings & Favorites**:
  - `rate_song(song_id, rating)`: Sets rating (1-5) or clears rating (`None`).
  - `get_song_rating(song_id)`: Retrieves user rating.
  - `toggle_favorite(song_id)`: Toggles favorite state and updates `favorited_at`.
  - `is_favorite(song_id)`: Checks favorite state.
  - `get_favorites_page(query, limit, offset)`: Filtered query of favorite tracks.
  - `get_rated_songs_page(min_rating, query, limit, offset)`: Filtered query of rated tracks.
- **Download Planning**:
  - `plan_playlist_download_all(playlist_id)`: Plans downloads for all tracks in playlist.
  - `plan_playlist_download_missing(playlist_id)`: Evaluates physical disk files and plans downloads only for missing tracks.
  - `plan_playlist_entry_download(playlist_id, song_id)`: Single-track download planning.
- **External Playlist Import**:
  - `import_external_playlist(url, target_name)`: Resolves external URLs (Spotify, YouTube, web playlists) using `ImportJobManager`, deduplicates canonical tracks against the local library, and populates a new playlist.

## User Interface & Views

### 1. `PlaylistsView` (`ui/views/playlists_view.py`)
- **Tabbed Interface**:
  - **My Playlists**: 3-column card grid displaying playlist name, description, and metrics chips (`X Tracks`, `✓ Y Downloaded`, `Z Missing`).
  - **⭐ Favorites**: Interactive table displaying all favorited tracks with live rating chips, quick-play, and download buttons.
  - **🌟 Top Rated**: Interactive table displaying 4-star and 5-star rated songs.
- **Top Actions**:
  - `➕ Create Playlist`: Modal dialog for custom playlist creation.
  - `📥 Import Playlist`: Modal dialog accepting Spotify, YouTube, or web playlist URLs.

### 2. `PlaylistDetailView` (`ui/views/playlist_detail_view.py`)
- **Hero Header**: Displays playlist title, description, and real-time metrics chips.
- **Dual Bulk Actions**:
  - `⬇ Download Missing`: Downloads undownloaded tracks only (skips owned files).
  - `⚡ Download All`: Re-verifies and downloads all playlist tracks.
- **Interactive Controls**:
  - `➕ Add Songs`: Search picker dialog to add canonical songs to the playlist.
  - `✏ Rename`: Inline modal to update playlist title and description.
- **Track Table**:
  - `#`: Position with `▲` and `▼` reordering buttons.
  - `Title`, `Artist`, `Album`: Clean typography with clickable links to Artist/Movie views.
  - `Rating`: 5 clickable star buttons (★) allowing instant rating adjustments.
  - `Fav`: Clickable heart button (❤️) for instant favorite toggling.
  - `Status`: `✓ Downloaded` badge or `NEW` indicator.
  - `Actions`: `▶ Play` for local files or `⬇ Download` for missing tracks.
  - `🗑`: Remove track button (preserves canonical song in library).
