# V5.5 — Curated Charts & Top 100 Subsystem

## Overview
Phase V5.5 introduces the **Curated Charts & Top 100** subsystem for the Tamil MP3 Downloader desktop application. This feature provides music listeners with ranked tracklists, weekly/daily chart snapshots, rank delta indicators (▲, ▼, NEW, ＝), and streamlined "Download Missing" workflows powered by the existing V5 canonical library architecture and download pipeline.

---

## Architecture & Relational Schema Integration

Rather than inventing a separate chart data store, V5.5 strictly reuses and extends the normalized SQLite architecture introduced in V5.1:

```
┌────────────────────────────────────────────────────────┐
│                        charts                          │
│  (id, name, chart_type, provider, updated_at, ...)     │
└──────────────────────────┬─────────────────────────────┘
                           │ 1:N
                           ▼
┌────────────────────────────────────────────────────────┐
│                     chart_entries                      │
│  (id, chart_id, rank, previous_rank, song_id, ...)     │
└──────────────────────────┬─────────────────────────────┘
                           │ N:1 (canonical link)
                           ▼
┌────────────────────────────────────────────────────────┐
│                         songs                          │
│  (id, title, artist, movie_id, state, quality_kbps...) │
└──────────────────────────┬─────────────────────────────┘
                           │ 1:N
                           ▼
┌────────────────────────────────────────────────────────┐
│                      song_sources                      │
│  (id, song_id, source_name, source_url, download_ref)  │
└────────────────────────────────────────────────────────┘
```

### Key Schema Elements:
1. **`charts` Table**:
   - `id`: Unique string slug (e.g., `chart-apple-music-tamil-top`, `chart-tamilmp3-trending`).
   - `name`: Human-readable title (e.g., "Apple Music — Tamil Top Hits").
   - `chart_type`: Classification badge (`stream_top`, `trending`, `all_time`, `top_100`).
   - `provider`: Data origin (`apple_music`, `tamilmp3`, `curated`).
   - `created_at` & `updated_at`: Snapshot timestamps.

2. **`chart_entries` Table**:
   - `(chart_id, rank)`: Composite unique constraint preventing duplicate ranking conflicts.
   - `rank`: Current position (1-indexed).
   - `previous_rank`: Prior snapshot rank used to calculate trend movement:
     - `▲ +N`: Ascending in chart.
     - `▼ -N`: Descending in chart.
     - `NEW`: New entry in the current snapshot.
     - `＝`: Rank unchanged.
   - `song_id`: Foreign key linked to canonical `songs(id)` or `NULL` before source resolution.

## Live Chart Discovery & Synchronization

The discovery subsystem is orchestrated by `library/charts.py:ChartDiscoveryService`:

1. **Apple Music Tamil Top Hits (Live RSS Feed)**:
   - Fetches live streaming rankings directly from Apple Music's public JSON RSS feed (`https://rss.applemarketingtools.com/api/v2/in/music/most-played/50/songs.json`).
   - Extracts real Tamil tracks, artists, and artwork.
   - Dynamically resolves canonical `songs` and links them into `chart_entries`.

2. **TamilMP3 Trending Releases (Live Portal Scraping)**:
   - Scrapes the latest trending releases and movie tracks directly from `https://tamilmp3.in`.
   - Populates tracks with direct high-bitrate download sources.

3. **Curated All-Time Evergreen Classics (Top 50)**:
   - A curated compilation of iconic Tamil classics (Illayaraja, A.R. Rahman, Harris Jayaraj, Anirudh).
   - Backfilled with canonical metadata and fallback seeds.

**Thread-Safety Guarantee**:
Chart browsing and card rendering are strictly decoupled from external scraping. Reading charts via `get_charts_page()` queries local SQLite in < 1ms. External network scraping occurs strictly on-demand via the `"Sync Charts"` button or background scheduler.

## Canonical Download Pipeline Integration

All chart downloads flow exclusively through the existing V5 download engine:

```
Chart Detail View
       │
       ▼
LibraryService.plan_chart_download_missing(chart_id)
       │
       ▼
DownloadPlanner.plan(song_ids)
   [Checks: SongState.OWNED on disk → Skips already downloaded]
   [Quality upgrade rules enforced: 320 kbps preferred, no downgrade]
       │
       ▼
LibraryService.execute_download_plan(plan, run_async=True)
       │
       ▼
DownloadRegistry.acquire_download() → state='DOWNLOADING'
       │
       ▼
HTTPDownloader / Scraper Provider
   [Downloads 320 kbps stream with chunked progress reporting]
       │
       ▼
Filesystem Storage & ID3 Metadata Tagging
       │
       ▼
DownloadRegistry.complete() → state='COMPLETED', songs.state='OWNED'
       │
       ▼
reconcile_library_files() & Live EventBus Notification
```

### Strict User-Facing Terminology
As mandated by architectural rules:
- **`✓ Downloaded`**: Audio file exists physically on disk and is verified.
- **`Not Downloaded`**: Track exists in library metadata but physical audio is missing.
- **`⬇ Download Missing`**: Enqueues only unacquired or missing tracks.
- **`⚡ Download All`**: Evaluates all tracks, respecting non-downgrade quality policies.
- **Forbidden terms eliminated**: "Owned", "Unowned", or low-level status codes are never shown in user-facing UI.

## Desktop User Interface (Tkinter / CustomTkinter)

### 1. Charts Overview (`ui/views/charts_view.py`)
- **Category Filter Tabs**: `All Charts`, `🏆 Top 100`, `🔥 Trending`, `🍎 Streaming Hits`, `📻 Classics`.
- **Search Bar**: Debounced filter by chart title or provider.
- **Card Grid**: Responsive 3-column layout showcasing:
  - Dynamic type icons (`🏆`, `🔥`, `🍎`, `📻`).
  - Total tracks, downloaded count, and missing count badges.
  - Formatted "View Chart →" action button.
- **Header Actions**: Top-right `"Sync Charts"` button triggering non-blocking background synchronization with live progress feedback.

### 2. Chart Detail View (`ui/views/chart_detail_view.py`)
- **Hero Banner**: Title, provider badge, last updated timestamp, and live statistics chips (`Tracks`, `✓ Downloaded`, `Missing`).
- **Primary Actions**:
  - `⬇ Download Missing`: Automatically plans and downloads only unowned tracks.
  - `⚡ Download All`: Downloads all tracks in the chart.
  - Search input for real-time in-chart track filtering.
- **Ranked Tracklist**:
  - `# Rank` badge (gold highlight for #1–#3).
  - `Trend` indicator (`▲`, `▼`, `NEW`, `＝`).
  - `Title` and click-navigable `Artist` and `Movie` links.
  - `Status` badge (`✓ Downloaded` vs `Not Downloaded`).
  - Action button (`▶ Play` for downloaded tracks, `⬇ Download` for missing tracks).
